## 2. 背景と目的

複数のサブスクリプションを契約している個人ユーザーは、サービスごとに異なる料金、通貨、請求日、無料期間を個別に確認する必要がある。

本システムは、それらの契約情報を一覧で整理し、契約状況と料金合計を把握できるようにすることを目的とする。

MVPでは、以下の価値をブラウザ上で検証する。

- サブスクリプション情報を登録、確認、編集、削除できる
- 次回請求日と無料期間をまとめて確認できる
- JPYとUSDの料金を分けて集計できる
- 登録した情報をページ再読み込み後も保持できる

---

## 3. 対象ユーザーと利用条件

### 3.1 対象ユーザー

- 複数のサブスクリプションを契約している個人ユーザー
- 契約内容、次回請求日、料金をまとめて確認したいユーザー

### 3.2 MVPの利用条件

- ユーザー認証は行わない
- 単一ユーザーが単一ブラウザで利用することを前提とする
- データは利用中のブラウザの `localStorage` に保存する
- ブラウザや端末をまたいだデータ同期は行わない
- 家族や複数ユーザーとのデータ共有は行わない

---

## 4. スコープ

### 4.1 MVP対象範囲

- サブスクリプションの新規追加
- 登録済みサブスクリプションの一覧表示
- 登録内容の編集
- サブスクリプションの削除
- プリセットカテゴリの選択
- ユーザー独自カテゴリの追加と保持
- JPYおよびUSDの料金管理
- 無料期間の管理
- 契約数、JPY合計、USD合計の表示
- 追加順および請求日順のソート
- `localStorage` によるデータ永続化
- Zodによる入力値および保存データの検証

### 4.2 MVP対象外

- ユーザー認証およびセッション管理
- Hono CRUD APIの実装
- Cloudflare D1連携
- 為替レート取得
- USDからJPYへの自動換算
- 通知
- Cloudflare Cron TriggersおよびQueues連携
- 検索
- 高度なフィルター
- グラフおよび分析
- 解約済み契約の管理
- カテゴリ名の編集および削除
- 家族および複数ユーザーでの共有

| FR-02-03 | システムはUSDで登録された料金の合計を表示すること |

| FR-02-05 | 一覧画面上部に新規追加ボタンを表示すること |

| ID | 要件 |

| ID | 要件 |
|---|---|

| FR-04-03 | 料金入力欄の左側に通貨記号、右側に通貨選択欄を表示すること |

| FR-04-06 | JPYの料金は整数で入力させること |

## 7. データ要件

### 7.1 サブスクリプション

| 項目 | 型・形式 | 必須 | 説明 |
|---|---|---:|---|
| `id` | 文字列 | 必須 | レコードを一意に識別するID |
| `name` | 文字列 | 必須 | サービス名 |
| `priceMinor` | 0以上の整数 | 必須 | 最小通貨単位の料金。JPYは円、USDはセント |
| `currency` | `JPY` または `USD` | 必須 | 通貨 |
| `categoryId` | 文字列 | 必須 | カテゴリID |
| `nextBillingDate` | `YYYY-MM-DD` | 必須 | 次回請求日 |
| `freeTrialDays` | 0以上の整数 | 必須 | 無料期間の日数。0は無料期間なし |
| `createdAt` | ISO 8601文字列 | 必須 | 登録日時。追加順と無料期間計算の基準 |
| `updatedAt` | ISO 8601文字列 | 必須 | 最終更新日時 |

金額は小数計算の誤差を避けるため、最小通貨単位の整数で保持する。

- JPY: `1500` は `¥1,500`
- USD: `1599` は `$15.99`

### 7.2 カテゴリ

| 項目 | 型・形式 | 必須 | 説明 |
|---|---|---:|---|
| `id` | 文字列 | 必須 | カテゴリを一意に識別するID |
| `name` | 文字列 | 必須 | カテゴリ名 |
| `isPreset` | 真偽値 | 必須 | プリセットカテゴリかどうか |

### 7.3 データフロー

MVPのデータフローは以下とする。

```text
UI → データアクセス層 → localStorage
```

本番用保存先へ移行した後は、以下を想定する。ただし、この移行自体はMVP対象外である。

```text
UI → データアクセス層 → Hono API（Cloudflare Workers）→ Cloudflare D1
```

ブラウザからCloudflare D1へ直接アクセスしない。

## 9. 受け入れ条件

| ID | 受け入れ条件 |
|---|---|
| AC-01 | 必須項目へ有効な値を入力すると、サブスクリプションを1件追加できる |
| AC-02 | 追加したデータが一覧に表示され、契約数と該当通貨の合計へ反映される |
| AC-03 | ページを再読み込みしても追加したサブスクリプションが残る |
| AC-04 | 登録済みデータを編集すると、変更内容が一覧とサマリーへ反映される |
| AC-05 | 削除確認をキャンセルすると対象データが残る |
| AC-06 | 削除確認で確定すると対象データだけが削除される |
| AC-07 | JPY選択時に整数料金を登録でき、`¥` で表示される |
| AC-08 | USD選択時に小数料金を登録でき、`$` で表示される |
| AC-09 | 通貨を変更しても入力済み金額が自動換算されない |
| AC-10 | JPYとUSDが混在しても、それぞれの合計が独立して正しく表示される |
| AC-11 | ユーザー独自カテゴリを追加し、次回以降のフォームで選択できる |
| AC-12 | 追加した独自カテゴリがページ再読み込み後も選択肢に残る |
| AC-13 | 無料期間を1日単位で増減でき、0日未満にできない |
| AC-14 | 無料期間0日が「無料期間なし」として扱われる |
| AC-15 | 追加順と次回請求日順を切り替えて一覧を表示できる |
| AC-16 | 必須項目が未入力または入力値が不正な場合、データが保存されない |
| AC-17 | 保存データを変更することなく、ソートによって表示順だけが変わる |

## 10. 前提および制約

- `localStorage` はMVP確認用の一時的な永続ストレージであり、本番用データベースとして扱わない
- `localStorage` の削除、ブラウザデータの消去、別ブラウザへの変更を行った場合、データは引き継がれない
- JPYとUSD間の換算は行わない
- MVPでは契約状態を「契約中」のみとして扱う
- MVPではカテゴリの編集および削除を行わない
- Hono APIおよびCloudflare D1への移行時は、サーバー側でもリクエストを検証する

## 12. MVP完了判定

以下をすべて満たした時点でMVP完成とする。

1. 本書の受け入れ条件 `AC-01` から `AC-17` を満たしている
2. `pnpm lint` が成功する
3. `pnpm build` が成功する
4. `pnpm exec vitest run` が成功する
5. `pnpm exec playwright test` が成功する
6. ブラウザ上で追加、一覧、編集、削除、永続化、カテゴリ追加、無料期間、ソート、通貨別集計を確認できる
